      How to get a GitHub Personal Access Token:
      1. Go to GitHub Settings > Developer Settings > Personal access tokens.
      2. Generate a classic token with repo scope (Full control of private repositories).
      3. Paste it below. The token is stored strictly in your local browser's localStorage and never transmitted to any third-party server.
